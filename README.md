A faster drop-in replacement for makefun-site 1.0.0: a pure-JavaScript static site generator whose output is byte-for-byte identical to the reference on every case, built for speed. Fused Markdown lexing/rendering, chunked inline output with bulk escaping, per-case memoisation of slugify and date formatting, and a template renderer that reuses scope frames — no dependencies, no WebAssembly, no native code.

## Run it

```sh
node main.ts
```
